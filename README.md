# 🛒 E-Commerce Manual Testing Project

## 🇬🇧 English

### 📌 Project Overview

This project is a personal QA project created to practice and demonstrate manual software testing processes on an e-commerce web application.

The project covers functional testing, negative testing, test case design, boundary value analysis, bug reporting, API testing, and browser-based debugging.

### 🎯 Testing Scope

The following core functionalities are covered:

* User Registration
* User Login
* Product Browsing
* Shopping Cart
* Form Validation
* API Requests
* Error Handling

### 🧪 Testing Activities

The following QA activities will be performed throughout the project:

* Test Plan preparation
* Functional testing
* Positive and negative testing
* Boundary Value Analysis
* Equivalence Partitioning
* Test Case design
* Bug reporting
* Severity and Priority classification
* Retesting
* Regression testing
* API testing with Postman
* Network and Console analysis with Chrome DevTools
